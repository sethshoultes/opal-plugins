# Opal plugins

Opal's plugins for Claude and ChatGPT. Opal looks after your membership website; these plugins let you talk to her from your AI assistant.

- [`opal/`](opal/): the Claude plugin. It connects Claude to Opal's server at `https://opalagent.app/mcp`. See its [README](opal/README.md).

To try it in Claude Code before it is listed in the directory:

```
/plugin install opal-agent --marketplace sethshoultes/opal-plugins
```

Opal's server itself is not in this repository.
